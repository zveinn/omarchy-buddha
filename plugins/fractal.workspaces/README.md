# fractal.workspaces

## Fractal FX

Cloned from omarchy.workspaces.

- Switching workspace: a saffron guru bead glides from the old button to the
  new one with two lotus-pink beads trailing it, like a mala being told. The
  new label blooms open (scale + fade, slight overshoot) while a pink ripple
  ring spreads from it.
- Hover: one soft breath of the label.

Setting `fractalFx`: "theme" (default, only on the `fractal` theme),
"always", or "off".
