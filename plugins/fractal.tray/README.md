# fractal.tray

## Fractal FX

Cloned from omarchy.tray.

- Icon click: a soft breath on the icon and a small lotus of petals opening
  from it with a ripple ring (fx/PetalBurst.qml).
- Tray menu and the tray-icons manager open/close with the lotus iris
  (fx/LotusIris.qml) and a mantra-mala ring round the card (fx/PanelRing.qml).
- Submenu: rows are written out of a string of mala beads, top to bottom,
  under a soft saffron thread of light (fx/Sacred.js decode).

Setting `fractalFx`: "theme" (default, only on the `fractal` theme),
"always", or "off".

Test hooks: `omarchy-shell fractal.trayfx click 0` etc.
